# Veriq

Milestone 1: Project foundation.

## Repository structure

- `contracts/` — Foundry Solidity project scaffold
- `app/` — Next.js + TypeScript application scaffold

## Commands

- `npm install`
- `npm run build:contracts`
- `npm run build:app`
- `npm run build`
- `npm run test:contracts`

## Notes

This milestone creates the project foundation only. No Veriq business logic or settlement contracts are implemented yet.
